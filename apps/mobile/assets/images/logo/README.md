# Logo assets

Place your NDTECH Collector logo files here.

Recommended files:

- `logo.PNG` — main app logo (provided)
- `logo_white.png` — for purple/dark headers
- `logo_mark.png` — icon-only version for small UI spots

Supported formats: PNG (preferred), JPG, WebP, SVG (if you add `flutter_svg` later).

Usage in Flutter:

```dart
Image.asset('assets/images/logo/logo.PNG')
```

After adding files, run:

```bash
flutter pub get
```
